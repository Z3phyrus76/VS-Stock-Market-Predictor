# Stock Market Predictor

This project is a simple stock market predictor built with Python. It pulls real-time stock data from Yahoo Finance using the `yfinance` API and applies a linear regression model to forecast the next 30 days of closing prices.

## Features

- Fetches the historical stock data from 2023 to the present date
- Trains a linear regression model using `scikit-learn`
- Forecasts the next 30 days of closing prices
- Plots actual vs. predicted prices with `matplotlib`
- Displays tables for the last 5 days of actual data and 30-day forecasted values

## Requirements

- Python 3.8 or newer
- pandas  
- numpy  
- matplotlib  
- yfinance  
- scikit-learn  

You can install the requirements by running:

```bash
pip install -r requirements.txt
